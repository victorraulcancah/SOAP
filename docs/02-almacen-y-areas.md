# Almacén, plano y áreas de trabajo

## Estructura del almacén

Cada almacén se organiza en niveles: **almacén → zona → pasillo → rack → nivel → posición**. Cada ubicación tiene un código único (etiqueta con código de barras o QR) y características propias:

- **Tipo:** almacenaje, picking, recepción, despacho, cuarentena, merma, devoluciones (y suministros).
- **Capacidad:** peso, volumen o cantidad de pallets.
- **Restricciones:** qué productos admite, condiciones de temperatura o humedad, acceso restringido.

## Plano visual

Sobre esa información se dibuja el plano del almacén, que permite:

- Ver dónde está cada producto.
- Ver mapas de ocupación y de productos de mayor riesgo.
- Ordenar las rutas de preparación de pedidos para recorrer menos.
- Identificar zonas con restricciones o incompatibilidades.

## Áreas de trabajo

Cada almacén se divide en áreas de trabajo con una función clara. Cada área aparece en el plano y tiene sus responsables.

| Área | Para qué sirve | Quién trabaja ahí |
|------|----------------|-------------------|
| Muelle de ingreso (recepción) | Descargar camiones y revisar lo que llega | Recepcionista, ayudantes de descarga |
| Control de calidad y cuarentena | Revisar y retener mercadería dudosa | Controlador de calidad |
| Almacenaje | Guardar la mercadería por tipo (arroz, menestras, azúcar, aceites, conservas) | Operarios de acomodo |
| Zona de preparación de pedidos (picking) | Recoger los productos de cada pedido | Preparadores de pedidos |
| Zona de espera de despacho (staging) | Reunir los pedidos listos, separados por cliente, tienda o ruta | Verificadores y despachadores |
| Embalaje (packing) | Verificar, embalar y etiquetar | Verificadores |
| Muelle de salida | Cargar los vehículos | Despachador, ayudantes, chofer |
| Devoluciones y merma | Separar lo devuelto, dañado o vencido | Controlador de calidad |
| Suministros y herramientas | Guardar cintas, papel, etiquetas y herramientas | Encargado de suministros |
| Oficina | Documentos, guías, facturas, permisos | Administrativo, responsable de cumplimiento |

Fuera del almacén también participan otras áreas de la empresa: ventas, tiendas o puntos de venta, compras, administración y transporte. El sistema las conecta con el almacén mediante pedidos y solicitudes.

Ver también: [Productos y ubicación](03-productos-y-ubicacion.md) para las reglas de dónde se guarda cada producto.
